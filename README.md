# Залікова робота

Булатицький Богдан Євгенович, студент 1 курсу.

У роботі два скрипти Streamlit і дві надані CSV-бази.

- `script1.py`: статистика учнів, чотири графіки та переведення класів.
- `script2.py`: вибір працівника, розрахунок зарплати та запис змін у CSV.

Установлення бібліотек:

```bash
python -m pip install -r requirements.txt
```

Запуск першого сценарію:

```bash
python -m streamlit run script1.py
```

Для запуску другого зупиніть перший через Ctrl+C:

```bash
python -m streamlit run script2.py
```

Скрипти та CSV мають лежати в одній папці. Потрібен Python 3.11+.

Випускним є 11-й клас. У наданій базі є також 12-ті класи. Під час переведення учні 11-х і 12-х класів вибувають, решта переходять на одну паралель вище: 1300 учнів стають 1060. Вихідний CSV учнів не змінюється. Кнопка «Початкові дані» скидає переведення.

У другому сценарії змініть ставку та стаж, перевірте зарплату й натисніть «Зберегти зміни». Оновиться тільки вибраний працівник. База спочатку записується у тимчасовий файл, який потім замінює основний CSV.

Формули:

- Директор: ставка * педагогічний стаж / 50 + стаж керування * 500.
- Вчитель: ставка * педагогічний стаж / 30.
- Охоронець: ставка + загальний стаж * 250.

У CSV поле `work_experience` означає відповідний стаж роботи, а `driving_experience` використовується як стаж керування директора. Назви колонок збережено. Бази містять 1300 учнів та 40 працівників.
