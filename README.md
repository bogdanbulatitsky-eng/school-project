# School project

Залікова робота Булатицького Богдана Євгеновича.

script1.py — аналітика учнів та переведення класів.
script2.py — розрахунок зарплат працівників.

Установлення:
python -m pip install -r requirements.txt

Запуск першого сценарію:
python -m streamlit run script1.py

Запуск другого сценарію:
python -m streamlit run script2.py
